## 3. 玩法总览（原版真实玩法）

### 3.1 剧情（据 JAR 中文文本还原）

主角 **卡特（Kurt）** 在一所混乱的医院里醒来，**失忆**。他是"狂热教授（Professor Crazy）"与"桥博士"的人体实验/克隆计划的产物（克隆编号与"泥瓦匠 / 赞恩"有关）。医院里满是疯狂医生、护士、看守人和被实验的病人。玩家要在**看守人的追捕**与**安全系统（监视器、哨兵枪、门锁）**的拦截下逐层向上逃，途中捡武器、药物、敌人的**器官**强化自己，并靠散落各层的**电脑终端/邮件**拼出真相，最终在天台**直升机**前与"泥瓦匠/赞恩"了断（"一次艰难的兄弟之战"）。

剧情载体：全屏文本（打字机式逐行显示）+ 电脑终端里可翻阅的"邮件/备忘录/尸检报告"，大量黑色幽默（例："我不需要电话。我有我的手机。" "这台电脑肯定有病毒。毕竟这是在医院……'对白痴的欢迎。'"）。

### 3.2 核心循环（一层 = 一个关卡单元）

```
醒来/进入新病区
  → 探索房间：撬锁柜/容器(PICKUP)、捡武器/药包/器官/钥匙
  → 躲监视器视野（红闪警报）或进"安全房间"用电脑终端黑入
  → 黑入：进入独立"骇客小游戏"画面，限时到达终点（障碍：黄=阻挡、橙=退回起点、红黄=失败并报警）
  → 骇客成功：关闭该层监视器 / 解锁大门 / 停用哨兵枪
  → 用钥匙开被锁的大门，或击杀/绕过巡视的敌人
  → 找到升降机，按开关 → 确认"使用后无法回头" → 进入下一层
  → 每张地图变化后自动存档
最终：天台直升机 + BOSS 战 → 结局
```

### 3.3 关卡结构

**8 组安全区（存档/检查点分组，`EN.GAME.lng` 原文）**：
`关键安全区 A1 / A2`、`B1 / B2`、`阿尔法 1 / 2`、`测试 1 / 2`、`C1 / C2`、`伽玛刀 1 / 2`、`三角洲 1 / 2`、`欧米茄`

**15 个病区主题（`EN.GAME.lng` 原文，按出现顺序）**：
`窖`、`地窖`、`酒会`、`急症室`、`外科`、`内科`、`心脏病`、`放射学`、`重症监护病房`、`门诊`、`实验室`、`精神病学`、`保健站`、`办事处`、`总部`

- 首关（教学）= **精神病学**（开场文本"精神障碍患者要求重返社会.在强大的休克疗法失败后主治医生停止了治疗…"）。
- 结局关卡 = **屋顶（总部天台）**，直升机 + BOSS 赞恩。
- 每层机制固定为"**钥匙 + 电脑 + 电梯**"三件套，难度靠敌人密度、摄像头数量、锁数量与地图复杂度递增。

### 3.5 系统机制

| 机制 | 说明 |
|---|---|
| 健康（HP） | 左侧红色横条；归零死亡 → 读取最近存档；死亡时显示"死亡原因"（`EN.GAME.lng`: `死亡原因: 识别标志:`） |
| 体力（Stamina） | 心形图标；冲刺/攻击消耗，心跳会加快、图标胀大；心跳太"平静"= 恢复中 |
| 自动存档 | 每张地图切换后自动保存到 RMS；"新的游戏将覆盖自动存档"；可手动存档/载入；可显示存档时间戳 |
| 警报 | 被监视器看到 / 骇客失败 / 触发红光会惊动看守人全图搜索；"在监视器红色信号警报闪烁前，不可以让警报被触发" |
| 监视器 | 有视野区域；进入即红闪；每层有"安全房间"可关掉全部监视器 |
| 哨兵枪 | 固定炮台，激活后自动索敌；对电敏感（泰瑟/除颤可瘫痪），可被黑入（推断为可反制/操控） |
| 骇客小游戏 | 独立画面、限时走迷宫；黄=阻挡、橙=退回起点、红黄=失败并触发警报 |
| 单向电梯 | 每层一部；使用后不可返回，电梯前需确认 |
| 容器 | 锁柜/箱子，靠近按 5 打开；内有武器、药、钥匙、弹药 |
| 瓦斯罐 | 可射击引爆、可推走；**连锁爆炸**；斧头也能引爆；"碰撞两次立即爆炸" |
| 可拾取 | 地面物品走过去即拾取（"物体在地板上很容易拿到，只要走过去拾起"） |
| 尸体/器官 | 测试对象尸体上可取器官，永久提升技能 |
| 扫描机 | 墙上扫描仪，可读取"关于你的资料"（剧情/属性信息） |
| 菜单 | 继续 / 新游戏 / 保存 / 载入 / 帮助 / 物品 / 武器 / 关于 / 设置（声音、音乐、音效、音量） |

### 5.5 状态机 / AI 规格

**玩家状态**：`IDLE / WALK / SPRINT / ATTACK / THROW / HURT / DODGE / DEAD / HACK`（骇客时为独立画面）
**敌人状态**：`IDLE / PATROL / ALERT(0.8s) / CHASE / WINDUP / ATTACK / STUNNED / REVIVE / DEAD`

```text
巡逻：沿路径点往返（速度 0.55×）；到点停留 0.6s，转向
警戒：距离 ≤ 4.5 tile 且 |角度| ≤ 55° 且视线无遮挡 → 头顶 "!" → ALERT 0.8s
追击：直线寻路（A* 到玩家所在房间门），丢失目标 3s 后回巡逻
攻击：距离 ≤ 武器射程 → WINDUP 0.35s → 命中判定 → 冷却
警报：任何敌人 ALERT 持续 1.5s 或被摄像头看到 → 全图敌人向玩家最后已知位置汇集，HUD 警戒红闪
```

### 5.8 骇客小游戏（独立画面）

- 视口 720×960，网格 12×16，格 60px；玩家是白色小方块，从左上到右下。
- 限时 20s（脑子升级 +2s/级，最多 +6s）。
- 障碍：黄色=不可通过；橙色=踩中退回起点；红黄=踩中立即失败并触发全图警报。
- 操作：摇杆 4/8 向，或拖拽屏幕；每关固定 2~3 个布局，随机种子存档保证重试一致。

### 5.9 动画 / 粒子 / 反馈清单

- 命中：白闪 60ms + 受击者后推 6px + 血粒子 8 个。
- 爆炸：4 帧火球（`#FFE137`→`#F67C00`→`#C0210D`）+ 8 个烟粒子（`#5A5A5A` alpha 递减）+ 屏幕震动 6px/0.2s。
- 枪口焰：2 帧三角 `#FFE137`+`#F67C00`，60ms。
- 拾取：物品向上飘 20px 淡出 + 1 个白色闪光。
- 警报：屏幕边缘红色呼吸（alpha 0~20%），警戒图标闪烁 2Hz。
- 冲刺：残影 3 帧（角色轮廓 alpha 20%）。
- 死亡：画面去饱和 0.4 + 慢动作 0.5s + "死亡原因"文本。
