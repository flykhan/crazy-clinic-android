# 《疯狂诊所》Android 重制版 · 游戏设计

> 依据 `docs/research.md` 的原版考证资料，结合触屏操作做的合理改良。

## 1. 一句话

失忆病人卡特被关在疯狂医院，从精神病学一路杀/潜行到屋顶，躲看守、黑电脑、捡器官强化自己，抢直升机逃走。

## 2. 核心循环（每层 4~12 分钟）

1. 在病区探索，捡武器/药品/钥匙卡/器官。
2. 躲开或击杀 7 类敌人；警报会引来追兵。
3. 找到**安保电脑**，玩**限时迷宫骇客小游戏**，关闭监控与哨兵枪。
4. 用**钥匙卡**打开锁门（`+`），走到**电梯**（`E`）按互动 → 进入下一层。
5. 每层间结算：击倒数 / 用时 / 死亡数；存档点按层解锁。
6. 第 10 层屋顶 BOSS 战：赞恩（三阶段），打赢后结局。

## 4. 操作（720×1280 竖屏，世界 720×960 + 控制区 320）

| 操作 | 方式 |
|---|---|
| 移动 | 左半屏拖拽虚拟摇杆（推满=冲刺，消耗体力） |
| 瞄准 | 右半屏拖拽（推过 55% 自动开火） |
| 攻击 | 右下红色「攻击」按钮（按住连发） |
| 互动 | 「互动」按钮：开门/电脑/储物柜/电梯/拾取 |
| 闪避 | 「闪避」按钮：0.35s 无敌，消耗体力 |
| 换武器 | 控制区左上「换武器」按钮循环可用武器 |
| 道具 | 「道具」按钮使用当前物品 |
| 暂停 | 世界区右上暂停键 |

聚焦/自动瞄准：右摇杆方向即瞄准方向；近战为扇形 90° 判定。

## 5. 战斗数值

- 玩家：HP 100、体力 100、移速 202px/s、冲刺 331px/s、闪避 12 体力。
- 武器 9 种（拳头/斧头/手术刀/手枪/霰弹枪/泰瑟枪/除颤器/本生灯/爆炸试管），数值见 `content/Balance.java`。
- 敌人 7 种 + BOSS；行为：巡逻 → 警觉 → 追击 → 攻击，护士会 3s 读条复活尸体，哨兵枪固定炮台怕电。
- 物品 8 种；器官 7 种永久强化（存 `SaveData.organsMask`）。

## 6. 骇客小游戏

独立 overlay：720×960 视口，12×16 网格（60px），拖拽白色光标从左上到右下；黄色不可通过、橙色退回起点、红黄立即失败并全图警报。限时 20s（脑升级 +2s）。成功 = 关闭摄像头/哨兵，目标更新为「前往电梯」。

## 7. 界面流程

标题 → (继续/新游戏) → 关卡选择 → 剧情简报 → 关卡 → 结算 → 下一层/重试 → …
设置（音效/音乐/震动/清档）、关于（版权声明）、教学（4 页）。

## 8. 美术方向

- 俯视 3/4 视角，医院：蓝灰地砖、石灰墙、深色墙裙、黄色警示条、血迹、日光灯。
- 角色：圆头 + 病号服（卡特：肤色 #F0CBAE、发 #E1C424、病号服 #DED6C3、绿短裤 #65D714、蓝拖鞋 #3570D7、描边 #2A2222）。
- 敌人配色区分：看守人红、医生暗红、护士粉、助手紫、病人绿、哨兵枪青、BOSS 紫金。
- 氛围：暗角 + 玩家光圈 + 日光灯光池；受伤红闪、拾取金闪、骇客蓝光。
- 全部 Canvas 图元绘制；禁止位图。
